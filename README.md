# Kerry1020

我做应用和开发工具，也在 Cloudflare Workers 上构建 MCP 服务。

项目涉及 JavaScript、Python、Kotlin 和 Swift，关注实用功能、清楚的使用边界，以及可以复现的测试和文档。

## 重点项目

### MCP 服务与 Web 工具

- [search-mcp-worker](https://github.com/Kerry1020/search-mcp-worker)：运行在 Cloudflare Workers 上的多引擎搜索 MCP 服务，包含公开的结果排序与合并逻辑。
- [calc-mcp-worker](https://github.com/Kerry1020/calc-mcp-worker)：无运行时依赖的数学 MCP 服务，覆盖数值计算、微积分、矩阵和统计等功能。
- [memory-mcp-worker](https://github.com/Kerry1020/memory-mcp-worker)：基于 Cloudflare KV 的持久化记忆 MCP 服务。
- [summarize-mcp-worker](https://github.com/Kerry1020/summarize-mcp-worker)：网页正文提取与轻量摘要 MCP 服务。
- [geo-mcp-worker](https://github.com/Kerry1020/geo-mcp-worker)：基于 OpenStreetMap 服务的地理编码、周边地点查询和路线规划。
- [webhook-inbox-mcp-worker](https://github.com/Kerry1020/webhook-inbox-mcp-worker)：接收并保存 Webhook 消息，提供 MCP 和 REST 接口读取。
- [image-mcp-worker](https://github.com/Kerry1020/image-mcp-worker)：通过 OpenAI 兼容接口生成图片的 MCP 服务。
- [time-mcp-worker](https://github.com/Kerry1020/time-mcp-worker)：时区查询、时间转换与时间差计算 MCP 服务。

### 应用与开发工具

- [Sleepy Android](https://github.com/Kerry1020/sleepy)：Kotlin 课程表应用，支持教务导入、多种课表视图和桌面小组件。
- [Sleepy iOS](https://github.com/Kerry1020/sleepy-ios)：使用 SwiftUI 和 WidgetKit 实现的 iOS 课程表版本。
- [WebVado](https://github.com/Kerry1020/webvado)：浏览器中的 FPGA 开发工作台，连接本机开源 FPGA 工具链。
- [SevenZipExtractor](https://github.com/Kerry1020/SevenZipExtractor)：使用 Swift 开发的 macOS 原生解压工具。
- [clash-verge-cli](https://github.com/Kerry1020/clash-verge-cli)：用于管理 Clash Verge 的跨平台命令行工具。
- [smartestu-homework-export](https://github.com/Kerry1020/smartestu-homework-export)：将未提交作业整理并导出为便于打印的 PDF。
- [qdp](https://github.com/Kerry1020/qdp)：Qobuz 的本地命令行工具和 Web 播放器项目镜像，Web 界面是我参与维护的部分。
